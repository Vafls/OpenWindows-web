About the Project

What is OpenWindows?

An open-source mission to rebuild Windows, piece by piece.

The Goal

To completely replace every component and piece of software in the Windows OS with free, open-source alternatives — creating a system that is safe, efficient, and customizable for everyone.

Our Values

Transparency over telemetry. Community over corporation. Every single line of code is public, auditable, and free — no hidden tracking, no ads, no licensing fees.

The Vision

A future where Windows users aren't locked into proprietary tools. Where every system utility — from the text editor to the task manager — can be replaced with something better, open, and community-driven.

"Software should be yours — readable, modifiable, and freely shared."
